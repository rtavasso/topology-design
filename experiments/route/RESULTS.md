## 2. What the routed arm learned (10 seeds, RM)

The committed route equals the oracle's on every stratum except PP: 1.00 on in1–in8 (P-words included), none3/4/8, len10–len32, alt4–alt32, deepP8; steps equal to the oracle's everywhere; p(HALT) exact by remaining distance; head column norms 0.6–0.9 (HOP), 1.8–2.4 (PREV), 0.8–0.9 (SET), 1.9–2.4 (HALT) with biases ≤ 0.3 — well inside AdamW's displacement bound (L24). The marginal and sampled readings agree with the committed one (p(target) 0.98 = 1 − ε). On PP runs the router reaches the flagged-with-pending state and takes PREV (2,411 of 2,497 first deviations), so the count value 2 is reached only in the 86 `PREV>HOP` cases; probe (a) shows it would be handled.

RM-T (traces) is identical in every final number; its only difference is the SET flip 100 steps earlier.

## 3. The deferral-0 failure: setup credit arrives through the state

Diagnostic (`diag_deferral0.py`, batch 16, lr 1e-3, λ = 0.02, one seed per arm, logits probed every 50 steps on a fixed batch; traces in `results_data/diag/`):

| state probed | oracle action (δ = 0) | δ = 0 router at step 50 / 200 / 1000 | oracle action (δ = 1) | δ = 1 router at step 50 / 200 / 1000 |
|---|---|---|---|---|
| flagged pair, (c, h) = (0, 0) | SET | p(SET) 0.31 / 0.25 / 0.22 | SET | p(SET) 0.40 / 0.16 / 0.38 (flips later; at batch 64 by step 600) |
| the oracle's PREV state | PREV at (flagged, 1, 1) | p(HOP) 0.99 / 0.99 / 1.00 | PREV at (landing, 1, 0) | p(PREV) 0.90 / 1.00 / 1.00 |
| any unflagged key, (1, 1) — a stray "set here" | HOP | p(HOP) 0.99 / 0.99 / 1.00 | HOP | p(HOP) 0.99 / 0.99 / 1.00 |
| any unflagged key, (1, 0) — a stray carried count | HOP | **p(PREV) 0.90 / 1.00 / 1.00** | HOP | **p(PREV) 0.89 / 1.00 / 1.00** |

Both routers learn the same thing in the first fifty steps, from the mass that strays into SET everywhere at init: **"set here ⇒ HOP; a carried count ⇒ PREV"** — a rule in the two state bits alone, identical for flagged and unflagged symbols. Under the deferred trigger that rule *is* the oracle's rule (c − h ≥ 1 ⇒ PREV), so the only thing left to learn is SET at flagged pairs, whose credit is then large (the PREV that follows is already in place), and it flips. Under the local trigger the oracle needs PREV at the *set-here* state when the pair is flagged — the opposite of what the strays taught for h = 1 — which requires the flag to be read again at that state against a decision already sharp at 0.99; and SET at the flagged pair pays only if that PREV exists. The two decisions wait for each other, and 6,000 × 64 steps do not break the wait, while the oracle program itself is a stable optimum once reached. So: the exact marginal credits a setup step quickly when the step's payoff decision is a function of the explicit state it writes, and not (within budget) when the payoff decision must re-read the context at a state the stray phase has labelled otherwise. The local trigger was expected to be the easy control; it is the hard case because its SET and its PREV sit at the same symbol and cannot be separated by the state.

This also reads the pilot's two-basin observation: at λ = 0.005 the same stray-taught rule ("carried count ⇒ PREV", with the predecessor's flag read to decide where) is kept and SET is applied everywhere to feed it.

## 4. The neural arms

LF (10 seeds) and LF-d0 (5): the hop chain is learned to perfection at the training depth (all-H words 1.00 at every k ≤ 8, 0.92 at the oracle depth, 0.99 under the stability exit) and nothing of the second circuit is learned in 6,000 steps under either trigger — P-words at chance at every evaluation (2,000 / 4,000 / 6,000) and at every depth of the deepest P. The two triggers give the same curves (`acc_P` difference −0.00 / −0.01), so the block's obstacle is not the two-match read of the deferred flag; it does not acquire a second gated circuit from next-token loss in this budget at all, with ≈ 380k P-word queries seen. S8 (3 × 12k) reaches k ≤ 2 (criterion at 400 / 2,600 steps; F26) and chance on P-words; S2 k = 1.

Caveat carried from review 1 (A.iii): RM vs LF contrasts given circuits + a learned selection rule against learned circuits + learned selection; the planted-gate block (D99) would separate "learning the gate" from "learning the circuit", and the LF-d0 result makes it more likely that the circuit is the obstacle.

## 5. Claims, labeled

- **Optimization.** The exact route marginal learns a four-action program with a setup step from next-token likelihood alone, 100 steps (≈ 6,400 episodes) behind supervision on oracle traces (RM vs RM-T; 10 and 5 seeds). Setup credit arrives through the explicit state: when the setup's payoff decision is a function of the state bits the setup writes, it is found early; when it must re-read the context at a state the init phase has labelled otherwise, it is not found in 6k steps (RM vs RM-d0; the planted-init stability run).
- **Mechanism (what the router conditions on).** The learned rule is Markov in the explicit state and generalizes exactly to the closure of its per-state decisions under the state encoding's geometry: length 4× and every training word at every depth (by construction once in range), the unseen count value 2 (probe (a), 10/10: the count is read ordinally), and not the unseen conjunction of two conditions (probe (b), pp 0.00, 10/10: the precedence is untrained). A learned router over an explicit state fails on new orders only where the data leave a decision undetermined.
- **Mechanism (what the state is for).** The explicit richer state buys a deterministic program at oracle cost, not Bayes accuracy: the symbol-only router reaches the same argmax of the route mixture by a stochastic setup step (p(target) 0.77, one sampled run right 77 % of the time, +1.2 actions per P-word, committed 0).
- **Expressivity.** The state-blind reference (a learned fixed program) is 0.84 / 0.85 in the two readings, as derived; the routed arm is 1.00; all of the gap is on words with a P.
- **Mechanism (the step cost; from the pilot, 2 seeds per cell, not preregistered).** λ selects between two exact-answer programs of different length; at λ = 0.005 the router keeps the stray-taught rule and sets everywhere.
- **Optimization (the neural carriers).** The looped block and the static stack learn the hop chain and not the second circuit, under either trigger, in the same budget (10 / 5 / 3 seeds).

## 6. What rung 1 does not say

Whether neural primitives on a shared state can replace the exact executor (rung 2); whether router and circuits survive joint training (rung 3); whether routes can be found without an exact E-step (rung 4); whether a few conjunction examples fix the precedence at every depth (D100); whether the block's failure is the gate or the circuit (D99); whether a curriculum or a different init breaks the deferral-0 wait; anything at scale. The novelty position relative to NPI / NRAM / Neural Program Lattices / CRL and to Mixture-of-Recursions is as stated in Entry 61 and the discussion of 28 Oct: a sharpening with four modest additions, not a stand-alone result.
