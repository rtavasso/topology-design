Building a block's weights by attention

The block that runs on each pass of the loop is not stored anywhere. It is assembled for the current input and state from a bank of stored blocks. These are the weights of a trained model: six primitives to learn, eight stored blocks of sixteen units, a six-dimensional state, four passes.
